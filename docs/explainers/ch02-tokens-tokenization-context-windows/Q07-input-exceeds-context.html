What Happens When Input Exceeds the Context Window?

Chapter 2 / Q07 — Context Overflow Strategies

Quick Take

When your input exceeds the context window, something has to give. The system must truncate, compress, or selectively retrieve -- and doing it badly means the model confidently answers with missing evidence. The question is not whether you lose information, but which information you can afford to lose.

Deep Dive

Models have hard limits. GPT-4 Turbo allows ~128k tokens, Claude supports up to 200k, but many production models are far smaller. When input exceeds the limit, naive truncation -- cutting from the end or the beginning -- is the simplest fix, but it can remove the very instructions or evidence the model needs. A prompt that says "answer the question at the end of this document" becomes useless if the end gets chopped off.

Sliding windows process the document in overlapping chunks, preserving local context but losing global coherence. Each window gets its own model call, and stitching the answers together is its own engineering problem. Summarization compresses earlier content, preserving gist but losing exact wording -- useful for conversation history, dangerous for legal or medical documents where precision matters.

The real lesson: even with large context windows, you rarely want to stuff everything in. Retrieval-based selection -- pick the most relevant chunks via embedding search -- almost always outperforms brute-force context filling, and it scales to corpora far larger than any context window.

def handle_overflow(chunks: list[str], max_tokens: int, strategy: str = "truncate"):
    """Demonstrate three strategies for handling context overflow."""
    token_counts = [len(c.split()) * 1.3 for c in chunks]  # rough estimate

    if strategy == "truncate":
        selected, total = [], 0
        for chunk, count in zip(chunks, token_counts):
            if total + count > max_tokens:
                break
            selected.append(chunk)
            total += count
        return selected

    elif strategy == "sliding_window":
        window_size = 3
        windows = []
        for i in range(0, len(chunks), window_size - 1):
            windows.append(chunks[i:i + window_size])
        return windows  # process each window separately

    elif strategy == "summarize":
        # In practice, you'd call an LLM to summarize
        early = " ".join(chunks[:len(chunks)//2])
        summary = f"[Summary of {len(chunks)//2} chunks: {early[:100]}...]"
        return [summary] + chunks[len(chunks)//2:]

chunks = [f"Chunk {i}: {'content ' * 20}" for i in range(10)]
for strategy in ["truncate", "sliding_window", "summarize"]:
    result = handle_overflow(chunks, max_tokens=200, strategy=strategy)
    print(f"\n{strategy}: kept {len(result)} items")
