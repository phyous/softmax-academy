What is SentencePiece and when is it preferable to classic tokenization?

Quick Take

SentencePiece treats the raw byte stream as input — no whitespace assumptions, no language-specific rules. It learns tokenization end-to-end, making it the go-to for multilingual and language-agnostic models.

Interactive Visual

Deep Dive

Classic tokenizers assume spaces separate words — fine for English, broken for Chinese, Japanese, Thai, and many other languages. SentencePiece (Kudo & Richardson, 2018) treats input as a raw character or byte sequence and learns segmentation during training. It bundles the vocabulary, normalization rules, and merge table into a single portable model file.

This means training and inference use the exact same tokenization — no preprocessing mismatch bugs. Models like T5, LLaMA, and PaLM use SentencePiece because it handles multilingual text, noisy web data, and code without language-specific hacks.

# SentencePiece usage example
import sentencepiece as spm

# Training (typically done once on your corpus)
# spm.SentencePieceTrainer.train(
#     input='corpus.txt', model_prefix='my_tokenizer',
#     vocab_size=32000, model_type='bpe'
# )

# Inference
sp = spm.SentencePieceProcessor()
sp.load('my_tokenizer.model')

texts = ["Hello world!", "日本語のテスト", "مرحبا بالعالم"]
for text in texts:
    pieces = sp.encode_as_pieces(text)
    ids = sp.encode_as_ids(text)
    print(f"{text}")
    print(f"  Pieces: {pieces}")
    print(f"  IDs:    {ids}\n")
