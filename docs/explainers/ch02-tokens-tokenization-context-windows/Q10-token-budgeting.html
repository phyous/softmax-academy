Quick Take

Design prompts backward from the budget, not forward from the content. Reserve space for what’s non-negotiable — system prompt, output, guardrails — then let everything else compete for what remains. Treat the context window as a hard engineering constraint, not a suggestion.

Deep Dive

Token budgeting is reliability engineering for LLMs. Start with the non-negotiable items: system instructions, safety guardrails, and a reserved output budget (you must know the max tokens your answer can use). What’s left is your “evidence budget” — the space for retrieved context, conversation history, and tool results. Production systems should measure actual token distributions (average and p99), set alerts on overflow, and treat the budget as a constraint to design around, not a number to hit.

Common mistakes: not reserving output space (the model’s response competes with input for the same window), stuffing all retrieved chunks without ranking, and ignoring that conversation history grows every turn. Multi-turn chatbots are especially dangerous — each user message and assistant reply adds to the running total until something gets silently truncated.

The best systems use token counting as a first-class monitoring metric alongside latency and error rate. Set alerts for when average usage crosses 80% of the window. Build dashboards that show p50, p95, and p99 token consumption. And always, always test with your longest realistic inputs, not your average ones.

Code

import tiktoken

enc = tiktoken.encoding_for_model("gpt-4")

class TokenBudget:
    def __init__(self, window_size: int, output_reserve: int):
        self.window = window_size
        self.output_reserve = output_reserve
        self.allocations = {}

    def allocate(self, name: str, text: str) -> int:
        count = len(enc.encode(text))
        self.allocations[name] = count
        return count

    @property
    def used(self):
        return sum(self.allocations.values()) + self.output_reserve

    @property
    def remaining(self):
        return self.window - self.used

    def report(self):
        print(f"Context Window: {self.window:,} tokens")
        for name, count in self.allocations.items():
            pct = count / self.window * 100
            print(f"  {name}: {count:,} ({pct:.1f}%)")
        print(f"  output_reserve: {self.output_reserve:,}")
        print(f"  REMAINING: {self.remaining:,}")
        if self.remaining < 0:
            print("  WARNING: OVERFLOW - reduce input or increase window")

budget = TokenBudget(window_size=8192, output_reserve=1500)
budget.allocate("system", "You are a helpful assistant for medical questions...")
budget.allocate("retrieval", "Patient records indicate... " * 50)
budget.allocate("history", "User: What about dosage?\nAssistant: The typical..." * 5)
budget.allocate("query", "What are the side effects of metformin?")
budget.report()
