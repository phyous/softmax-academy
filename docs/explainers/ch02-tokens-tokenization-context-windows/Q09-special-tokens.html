Special Tokens

Chapter 2 — Tokens, Tokenization & Context Windows

Quick Take

Special tokens are invisible traffic signals — [BOS], [EOS], [SEP], [PAD], [MASK] — that tell the model where sequences start, end, and transition. They never appear in the text you read, but they shape every prediction the model makes. Get them wrong and the model misinterprets the entire input structure.

Deep Dive

Special tokens are metadata embedded in the token stream. They’re never shown to users but they’re critical for the model’s understanding of structure. [BOS] and [EOS] mark sequence boundaries — without them, the model doesn’t know where one input ends and another begins. In chat models, role markers (<|user|>, <|assistant|>) tell the model whose turn it is; remove them and the model can’t distinguish instructions from conversation. [PAD] tokens fill batches to equal length for efficient GPU processing. [MASK] tokens (in BERT-style models) mark positions the model should predict.

During fine-tuning, mismatched special token handling is one of the most common silent bugs — the model trains successfully but behaves unpredictably because it learned the wrong structural patterns. If you switch tokenizers or model families, the special token vocabulary changes too, and your carefully formatted prompts may parse into nonsense.

Think of special tokens as the punctuation of machine understanding: invisible to readers, indispensable to parsers. Every chat template, every fine-tuning run, and every API call relies on them being exactly right. The “Break It” button above shows what happens when they’re not.

Code

from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")

# Show special tokens in the vocabulary
print("Special tokens:", tokenizer.all_special_tokens)
print("Special token IDs:", tokenizer.all_special_ids)

# See how special tokens frame a sequence
text = "Tokens are the atoms of language models."
encoded = tokenizer(text, add_special_tokens=True)
tokens = tokenizer.convert_ids_to_tokens(encoded["input_ids"])
print(f"\nInput: {text}")
print(f"With special tokens: {tokens}")
print(f"IDs: {encoded['input_ids']}")

# Chat-style formatting (GPT-style)
chat = [
    {"role": "system", "content": "You are helpful."},
    {"role": "user", "content": "What is a token?"},
]
