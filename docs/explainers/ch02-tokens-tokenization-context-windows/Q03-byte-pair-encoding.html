Quick Take

BPE builds a vocabulary by starting with individual characters and repeatedly merging the most frequent pair. The result: common patterns get compact tokens while rare words decompose gracefully. No word is truly "unknown."

Deep Dive

Before BPE, NLP models used fixed word vocabularies. Any word not in the dictionary was replaced with a special [UNK] token — a dead end that threw away information. Proper nouns, typos, new slang, and multilingual text were constant headaches. BPE eliminated this problem entirely.

The algorithm is simple. Start with a vocabulary of individual bytes (or characters). Scan the training corpus, count every adjacent pair, and merge the most frequent pair into a single new token. Repeat until the vocabulary reaches a target size (commonly 32k–200k tokens). The result is a spectrum of granularity: very common words like "the" get a single dedicated token; moderately common morphemes like "ing" or "tion" share tokens; rare strings decompose into small pieces that are still meaningful.

This open-vocabulary property is why BPE and its variants (WordPiece, Unigram, SentencePiece) became the default in GPT, LLaMA, Claude, and virtually every modern LLM. The model can represent any input — any language, any typo, any emoji — using a finite, fixed vocabulary. Training learns the merge table once; inference applies it deterministically.

Code

from collections import Counter

def learn_bpe(corpus, num_merges):
    """Simplified BPE: learn merge rules from a corpus."""
    tokens = [list(word) + ['</w>'] for word in corpus.split()]
    merges = []
    for i in range(num_merges):
        pairs = Counter()
        for word in tokens:
            for a, b in zip(word, word[1:]):
                pairs[(a, b)] += 1
        if not pairs:
            break
        best = pairs.most_common(1)[0]
        merges.append(best)
        new_token = best[0][0] + best[0][1]
        tokens = [merge_pair(word, best[0], new_token) for word in tokens]
        print(f"Merge {i+1}: '{best[0][0]}' + '{best[0][1]}' -> '{new_token}' (count: {best[1]})")
    return merges

def merge_pair(word, pair, new_token):
    result = []
    i = 0
    while i < len(word):
        if i < len(word) - 1 and word[i] == pair[0] and word[i+1] == pair[1]:
            result.append(new_token)
            i += 2
        else:
            result.append(word[i])
            i += 1
    return result

learn_bpe("low low low low low lowest lowest newer newer newer", num_merges=5)
